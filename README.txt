Rizwan Shoukat - Portfolio Website
==================================

Kaise chalayein:
  index.html ko kisi bhi browser (Chrome, Edge, Firefox) mein double-click karke kholein.
  Fonts Google Fonts se aate hain, is liye internet on hona chahiye.

Folder structure:
  index.html              Website ka HTML (saare sections)
  css/style.css           Saari styling, colors, animations, mobile layout
  js/main.js              Saari animations aur interactions (loader, cursor, sliders,
                          flipbook, 3D book, lightbox, testimonials, waghera)
  assets/images/          Saari images (WebP format, web ke liye compressed)
  assets/tools/           Tools wale icons
  assets/Rizwan_Shoukat_CV.pdf   Download CV button wali file

Images ke naam (assets/images):
  hero.webp        Hero aur About ki pic
  ui_*.webp        UI/UX section (app screens, process, presentation shots)
  br*.webp         Branding (Fork & Flame)
  sp*.webp         Social media posts (phone carousel)
  ss*.webp         Social media campaign sets
  bk01_*.webp      Brochure: TechCon Southwest 2026 (24 pages)
  bk02_*.webp      Brochure: TechCon 2026 Events (36 pages)
  bf*.webp         Bi-fold brochure
  book_*.webp      3D book (front, spine, back)
  bm*.webp         Book cover mockups
  pk*.webp         Packaging
  am*.webp         Amazon listing images

Online lagane ke liye:
  Poora folder kisi bhi hosting par upload kar dein (Netlify, Vercel, GitHub Pages,
  Hostinger, waghera). index.html main file hai.

Zaroori:
  Testimonials section mein reviews abhi sirf jagah bharne ke liye hain (asli clients
  ke nahi). Live karne se pehle js/main.js mein "TESTIMONIALS" wale hisse (var TS=[...])
  mein asli clients ke naam aur feedback daal dein.
